# Smooth scroll (Lenis)

`initSmoothScroll(root?)` — Lenis syncé au ticker GSAP + `ScrollTrigger.update`.

- Desktop ≥992 uniquement ; mobile scroll natif.
- Skip si `prefers-reduced-motion` ou Lenis CDN absent.
- Peer : Lenis 1.3 + GSAP + ScrollTrigger (CDN). CSS : `lenis.css` + classe `html.has-lenis`.
